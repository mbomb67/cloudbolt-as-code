# Domain OU

Specific OU to join the domain. Will only be used if the 'Domain to Join' is specified.

Parameter `domain_ou` (String). Source Control Repos does not sync parameters: the Content Package Manager UI extension writes this folder when it exports a package that lists the parameter, and its Sync creates the parameter, or updates the one with this name.
