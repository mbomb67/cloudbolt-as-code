# Domain Service Account

Connection info whose domain account CloudBolt signs in to the server with after the Join Windows Server to AD Domain action joins it to its Domain OU.

Parameter `domain_service_account` (String). Source Control Repos does not sync parameters: the Content Package Manager UI extension writes this folder when it exports a package that lists the parameter, and its Sync creates the parameter, or updates the one with this name.

Options generated by:

- [Generate Options for Domain Service Account](../../orchestration_actions/HPA-g8pqv6uv/)
