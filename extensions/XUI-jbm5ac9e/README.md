# Server Workflows (XUI)

Adds **Admin > Custom Extensions > Server Workflows**, where CB Admins build the workflows that the [Run Workflow](../../server_actions/SVA-j7rbsh39/) server action runs on a server: a name, filters, and an ordered list of steps, each an existing Remote Script, CloudBolt plug-in, webhook, email or copy-file action with its inputs set to a fixed value, asked for when the workflow runs, or taken from an earlier step's output.

The step picker offers only actions that can run on every server the workflow's filters allow, and lists the others with the reason. Copy makes a disabled copy for review. The page needs the `server_workflows` shared module, which arrives with Run Workflow, so sync that action (or `packages/PKG-vfnycv8s`) first, then restart the web server (`systemctl restart httpd`), because the extension adds URL paths. The same operations are available as JSON under `/xui/server_workflow_builder/api/` (CB Admin, session auth with CSRF). Everything requires CB Admin.
