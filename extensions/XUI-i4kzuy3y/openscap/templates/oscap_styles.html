{% comment %} Styles of the OpenSCAP server tab and resource tab. oscap_assets.html and oscap_resource_assets.html include this; each tab is a page of its own, so it is injected once per page. Colors derive from CloudBolt's theme tokens (--bs-body-color, --surface, --bs-primary/-success/-warning/-danger), so Branded Themes and dark mode (html[data-bs-theme="dark"]) re-theme the tab. Cards are a transparent overlay of the text color, never a hardcoded fill. The header, tables and the history list are unframed. Everything is scoped under the root element. {% endcomment %}
