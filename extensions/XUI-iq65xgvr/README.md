# Content Package Manager (XUI)

Adds **Admin > Custom Extensions > Content Packages**, where CB Admins define content packages: named lists of top-level blueprints, actions, plugins, shared modules, and UI extensions that ship together (forms and form functions are left out because they only sync with their parent). A package's details page lists its members and every dependency CloudBolt's own repository export writes with them; a member shows red when it no longer exists on the appliance and amber when its Remote Source URL is not on the package's home repository and branch. Each definition is one value of the parameter `content_package_store`, which is created on first use in the `content_packages` namespace and so stays off the Parameters list. Re-syncing or removing the extension keeps the definitions, and deleting a package removes only its definition; deleting that parameter deletes every package. The same operations are available as JSON under `/xui/content_packages/api/` (CB Admin, session auth with CSRF). Export, sync, and import from a repository are not built yet. The extension adds URL paths, so restart the web server (`systemctl restart httpd`) after syncing it.
