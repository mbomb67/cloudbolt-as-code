# Content Package Manager (XUI)

Adds **Admin > Custom Extensions > Content Packages**, where CB Admins define content packages: named lists of top-level blueprints, actions, plugins, shared modules, and UI extensions that ship together (forms and form functions are left out because they only sync with their parent). A package's details page lists its members, every dependency CloudBolt's own repository export writes with them, and the jobs of its last sync. A member shows red when it no longer exists on the appliance and amber when its Remote Source URL is not on the package's home repository and branch.

- **Export** runs as a CloudBolt job, so the dialog returns at once and the job log records each member. The first export registers a plugin named "Content Package Manager: Export" whose code is this extension's `export_job.py`, so nothing else needs syncing. The job pushes each member with CloudBolt's own Push to repository (one commit per member, carrying its plugins, shared modules, and forms) as the user who started it, then commits the manifest to `packages/<PKG-id>/`, plus a README the first time. The details page shows the job and each member's result; a second export of the same package is refused until the first finishes.
- **Sync** starts one CloudBolt sync job per member, chained so they run one at a time: shared modules and plugins first, blueprints last. A failed job holds the rest; fix the content, push it, and Rerun the failed job from its page to continue. As with any sync, a blueprint's group permissions are reset to what its metadata lists.
- **Import from repository** lists the `packages/` manifests on a branch and registers the chosen one by its PKG id, updating the package when that id is already registered, then opens Sync. Exported manifests are therefore the backup of the definitions.

Branch names must not contain a slash, because CloudBolt reads the branch from one part of each Remote Source URL. Each definition is one value of the parameter `content_package_store`, created on first use in the `content_packages` namespace so it stays off the Parameters list; deleting that parameter deletes every package. The same operations are available as JSON under `/xui/content_packages/api/` (CB Admin, session auth with CSRF). The extension adds URL paths, so restart the web server (`systemctl restart httpd`) after syncing it.
