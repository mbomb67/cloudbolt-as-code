{% comment %} Styles and script for the Budgets tab on the Group page. The script defines window.ebxInit(rootId, config), which the tab template calls once the tab loads. Styles derive from CloudBolt's theme tokens (--bs-*, --surface, --neutral-*) so Branded Themes and dark mode re-theme the tab; the charts read the same tokens from computed styles and redraw when data-bs-theme changes. All DOM is built with text nodes, never by writing API strings into HTML. {% endcomment %}
