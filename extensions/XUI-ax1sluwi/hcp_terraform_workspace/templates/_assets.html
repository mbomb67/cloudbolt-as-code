{% comment %} Shared styles and panel loader for the HCP Terraform Workspace tabs, the same look as the EKS, AKS, GKE, OpenShift and StormForge extensions' tabs. Styles are inline and theme-safe: tokens derive from --bs-primary / --bs-body-color / --surface like CloudBolt's own order and resource pages, so Branded Themes and dark mode re-theme the tabs without an asset build. Cards are set off from the tab by a transparent overlay of the theme's text color (a background and a border, never opacity, so text keeps its color). Blocks marked tf-flat, the page headers and the tables, have no fill or frame and sit on the tab's own surface. Class names carry a tf- prefix so they never meet the other extensions'. {% endcomment %}
