{% load i18n %} {% comment %} Shell of the Vulnerabilities tab of a resource. It rolls up the known vulnerabilities of the resource's own servers (not those of sub-resources) that the viewer may see, and can scan them all. Everything in it is drawn by vuln_fleet_assets.html from five JSON routes (urls), one page at a time. The tab is injected into the resource page after it loads, and can be injected again, so the script starts at once and once per root. CloudBolt keeps the open tab in the URL hash (#tab-vulnerabilities), so the root has data-vuln-nohash: the script keeps the view in memory and never touches the hash. The styles are vuln_styles.html, scoped to #vuln-root; the few rules this tab adds are in the second style block, built from the same variables. The "Scan all servers" button is always rendered, hidden: the summary answer's can_scan shows it, so this view never works out which servers may be scanned. Context: resource, no_servers, urls (summary, cves, cve_servers, servers, scan), shell (is_admin, settings_url, fleet_url). {% endcomment %} {% include "io_cloudbolt_vulnerabilities/templates/vuln_styles.html" %}
