# Windows AD Domain Join

Joins provisioned Windows servers to the Active Directory domain of their domain_to_join LDAP Utility, with a type-ahead OU picker for domain_ou and deletion of the computer object at decommission.

Content package `PKG-nf407lm5`, version 1.0.0. Sync it from the Content Packages admin page (Content Package Manager UI extension).
