# Alert Remediation

Maps monitoring alerts posted to an inbound webhook to a Restart Apache server action that health-checks the server and escalates to ServiceNow and Microsoft Teams when it is still unhealthy.

Content package `PKG-yo8vupwq`, version 1.0.0. Sync it from the Content Packages admin page (Content Package Manager UI extension).
