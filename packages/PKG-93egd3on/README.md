# Server Tasks

Adds one Run Task server action that lists the Remote Scripts that can run on a server and runs the chosen one with its own inputs, plus Windows and Linux base task scripts and two service-management examples.

Content package `PKG-93egd3on`, version 1.0.0. Sync it from the Content Packages admin page (Content Package Manager UI extension).
