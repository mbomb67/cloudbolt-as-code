# Data Disk Blueprints

Deploys Windows Server and Oracle Linux VMs with order-time data disks through the Windows, Oracle Linux, and disk map blueprints, with the Post-Provision orchestration actions that attach the disk map's disks and prepare them inside the guest.

Content package `PKG-t1k7drin`, version 1.0.0. Sync it from the Content Packages admin page (Content Package Manager UI extension).
